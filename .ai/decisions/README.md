# Decisions

> Generated by Meridian from its decision register. Record a new decision, or supersede one, in Meridian rather than editing this file: the next scaffold run rewrites it. A hand edit here stops Meridian updating the file. To move one into Meridian, record it there, delete this file, and run the scaffold again.

One file per decision recorded in Meridian: the question, what was decided and why, and the options that were considered. Read the one that bears on your change before you change it -- the question may already be settled. A decision still awaiting a call is not here; `list_decisions` shows the queue.
