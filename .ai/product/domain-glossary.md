### Concepts in this repository

### Enquiry Tracker
Harbour Freight's enquiry tracker: a Flutter desktop application for Windows used by the sales team on a shared front-desk PC. Stores its data in a local SQLite database and signs users in with local usernames and passwords. Runs without internet access.

### Desktop UI
The screens people see and use: sign-in, home, and user administration today. Screens and the controllers that drive them. Enquiry screens do not exist yet.

### Enquiry Tracker Core
The application's business rules and data access: authentication, user administration and database setup today. Enquiry rules and storage do not exist yet.

### Sqlite
The local SQLite database file (harbour_freight.db) held in the Windows user's application-support folder. Currently holds users and their roles. The database is created and upgraded by the application itself.
